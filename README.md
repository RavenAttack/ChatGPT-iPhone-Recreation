# ChatGPT iPhone iOS 26 Recreation

A lightweight HTML/CSS/JS recreation of a futuristic iPhone home screen concept.

## Run locally

Open `index.html` directly in your browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Features

- iPhone-style frame, dynamic island, and status bar
- Glassmorphism widgets and app icon grid
- Live time/date using JavaScript
- Long-press interaction to toggle icon wiggle/edit mode
