# iOS 26 Unboxed Recreation

A full-screen HTML/CSS/JS concept experience that starts like a freshly unboxed iPhone setup flow and transitions into a functional iOS-style home screen.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Included interactions

- Full-screen interface with setup flow screens
- Continue/Finish setup actions
- Live status-bar time and date
- Clickable app and dock buttons that trigger system-style toasts
- Long-press on the home screen to toggle wiggle/edit mode
- Automatic iPad mode on landscape devices plus manual mode toggle
